Аналитический кейс: Students Performance in Exams

Пошаговая инструкция для ученицы: от гипотезы до обоснования продуктовой идеи — только на pandas, без NumPy.

Шаг 1 — Постановка

Гипотеза и продуктовая идея

Гипотеза

Студенты, прошедшие курс подготовки к экзамену (test preparation course = completed), показывают значимо более высокие результаты по всем трём предметам (math, reading, writing), чем те, кто курс не проходил. При этом эффект подготовки может различаться в зависимости от пола, типа питания (прокси социально-экономического статуса) и уровня образования родителей.

Продуктовая идея

Сервис «ExamPrep Coach» — персональный трекер подготовки к экзаменам:

  • диагностирует текущий уровень по трём предметам;
  • строит индивидуальный план подготовки с учётом слабых зон;
  • подбирает интенсивность и формат занятий под профиль ученика (пол, тип питания как прокси СЭС, образование родителей);
  • прогнозирует ожидаемый прирост баллов на основе исторических данных.
Почему это востребовано: данные показывают, что подготовка связана с заметным приростом баллов, но эффект неоднороден — значит, персонализация (а не «один курс для всех») создаёт ценность.

Шаг 3 — Данные

Загрузка датасета и выбор столбцов

Для проверки гипотезы нужны столбцы: gender, parental level of education, lunch, test preparation course и три целевых балла: math score, reading score, writing score.

Загружаем файл и оставляем только нужные столбцы через df[cols].

Показать код: загрузка и выбор столбцов 
import pandas as pd

df = pd.read_csv('StudentsPerformance.csv')

cols = ['gender', 'parental level of education', 'lunch',
        'test preparation course', 'math score', 'reading score', 'writing score']

df = df[cols]
print(df.head())
print(df.shape)
Теория: pd.read_csv() читает файл в DataFrame — таблицу с именованными столбцами. Выбор подмножества столбцов через df[cols] возвращает новый DataFrame и не меняет исходный, пока мы не присвоим результат.

Очистка только нужных данных

Проверяем пропуски, дубликаты и диапазоны баллов. Чистим только те столбцы, которые нужны для гипотезы.

Показать код: проверка качества данных 
# Пропуски по каждому столбцу
print(df.isna().sum())

# Полные дубликаты строк
print('Дубликатов:', df.duplicated().sum())

# Диапазоны баллов
print(df[['math score', 'reading score', 'writing score']].describe())

# Уникальные значения категориальных признаков

Теория: isna().sum() считает пропуски по столбцам; duplicated().sum() — число полных дубликатов строк; describe() даёт count / mean / std / min / квантили / max. В этом датасете пропусков и дубликатов нет, баллы лежат в диапазоне 0–100 — дополнительная очистка не требуется.
Шаг 5 — Фичи

Генерация новых признаков

Создаём производные признаки, которые понадобятся для группировок и визуализаций.

  • avg_score — средний балл по трём предметам;
  • total_score — сумма баллов;
  • prep_completed — бинарный флаг прохождения подготовки (1/0);
  • parent_edu_level — порядковая шкала образования родителей (0–5);
  • low_ses — прокси низкого социально-экономического статуса (free/reduced lunch).
Показать код: создание признаков 
# Средний и суммарный балл
df['avg_score']   = df[['math score', 'reading score', 'writing score']].mean(axis=1)
df['total_score'] = df[['math score', 'reading score', 'writing score']].sum(axis=1)

# Бинарный флаг подготовки
df['prep_completed'] = (df['test preparation course'] == 'completed').astype(int)

# Порядковая шкала образования родителей
edu_order = {
    'some high school': 0,
    'high school': 1,
    'some college': 2,
    "associate's degree": 3,
    "bachelor's degree": 4,
    "master's degree": 5
}
df['parent_edu_level'] = df['parental level of education'].map(edu_order)

# Прокси социально-экономического статуса
df['low_ses'] = (df['lunch'] == 'free/reduced').astype(int)

print(df[['avg_score', 'prep_completed', 'parent_edu_level', 'low_ses']].head())
Теория: .mean(axis=1) считает среднее по строке (по предметам); .astype(int) превращает True/False в 1/0; .map(dict) заменяет категории по словарю — удобно для порядковых шкал.
Шаг 6 — Проверка гипотезы

Статистические показатели, фильтрация и группировка

6.1 Описательные статистики по группам

Показать код: сводка по группам подготовки 
summary = df.groupby('test preparation course')[
    ['math score', 'reading score', 'writing score', 'avg_score']
].agg(['mean', 'median', 'std', 'count'])

print(summary.round(2))

6.2 Абсолютная и относительная разница средних

Показать код: разница средних и прирост в % 
grp = df.groupby('test preparation course')[
    ['math score', 'reading score', 'writing score', 'avg_score']
].mean()

diff = grp.loc['completed'] - grp.loc['none']
rel  = (diff / grp.loc['none'] * 100)

result = pd.DataFrame({'абс. разница': diff.round(2),
                       'прирост, %':  rel.round(1)})
print(result)
Теория: groupby(...).agg([...]) позволяет считать несколько статистик сразу. .loc[...] — доступ по метке индекса; вычитание Series выравнивается по индексам, что удобно для расчёта эффекта.

6.3 Проверка значимости без NumPy и SciPy

Чтобы остаться в рамках pandas, сравним группы через bootstrap (ресэмплинг) — оценим, как часто разница средних в случайных перестановках метки подготовки оказывается не меньше наблюдаемой.

Показать код: bootstrap-тест разницы средних 
observed = df.loc[df['prep_completed'] == 1, 'avg_score'].mean() \
         - df.loc[df['prep_completed'] == 0, 'avg_score'].mean()
print('Наблюдаемая разница:', round(observed, 2))

# 1000 перестановок флага подготовки
n_perm = 1000
diffs = []
scores = df['avg_score'].reset_index(drop=True)
labels = df['prep_completed'].reset_index(drop=True)

for _ in range(n_perm):
    shuffled = labels.sample(frac=1, random_state=None).reset_index(drop=True)
    d = scores[shuffled == 1].mean() - scores[shuffled == 0].mean()
    diffs.append(d)

diffs = pd.Series(diffs)
p_value = (diffs >= observed).mean()
print('p-value (перестановочный тест):', round(p_value, 4))
Теория: перестановочный тест проверяет нулевую гипотезу «метка подготовки не связана с баллом». Мы многократно перемешиваем метки и смотрим, насколько часто случайная разница средних превышает наблюдаемую. Если p-value мало (< 0.05) — эффект статистически значим. .sample(frac=1) перемешивает строки, reset_index(drop=True) выравнивает индексы.

6.4 Неоднородность эффекта

Показать код: эффект по полу, lunch и образованию родителей 
# Эффект по полу
effect_gender = df.groupby(['gender', 'test preparation course'])['avg_score'] \
                  .mean().unstack()
effect_gender['эффект'] = effect_gender['completed'] - effect_gender['none']
print(effect_gender.round(2))

# Эффект по типу питания
effect_lunch = df.groupby(['lunch', 'test preparation course'])['avg_score'] \
                 .mean().unstack()
effect_lunch['эффект'] = effect_lunch['completed'] - effect_lunch['none']
print(effect_lunch.round(2))

# Эффект по уровню образования родителей
effect_edu = df.groupby(['parent_edu_level', 'test preparation course'])['avg_score'] \
               .mean().unstack()
effect_edu['эффект'] = effect_edu['completed'] - effect_edu['none']
print(effect_edu.round(2))
Теория: groupby([...]).mean().unstack() превращает длинную таблицу в широкую: строки — один признак, столбцы — значения второго. Это удобно, чтобы посчитать эффект как разность двух столбцов.

6.5 Фильтрация «рисковой» группы

Целевая аудитория продукта — студенты без подготовки и с низким СЭС.

Показать код: фильтрация и размер рисковой группы 
risk = df[(df['prep_completed'] == 0) & (df['low_ses'] == 1)]

print('Размер рисковой группы:', len(risk),
      f'({len(risk) / len(df) * 100:.1f}% от всех)')

print(risk[['math score', 'reading score', 'writing score']].mean().round(2))
Теория: булевы маски комбинируются через & (И), | (ИЛИ), ~ (НЕ). Каждое условие — Series из True/False; df[mask] возвращает отфильтрованные строки.

7.5 Нестандартная визуализация: «радар» профилей по предметам

Радар-чарт хорошо показывает многомерный профиль: три предмета — три оси. Сравниваем средние профили двух групп.

Показать код: radar chart 
from math import pi

categories = ['math score', 'reading score', 'writing score']
N = len(categories)
angles = [n / float(N) * 2 * pi for n in range(N)]
angles += angles[:1]

fig, ax = plt.subplots(figsize=(6, 6), subplot_kw=dict(polar=True))

for label, color in [('completed', 'green'), ('none', 'red')]:
    vals = df[df['test preparation course'] == label][categories].mean().tolist()
    vals += vals[:1]
    ax.plot(angles, vals, color=color, label=label)
    ax.fill(angles, vals, color=color, alpha=0.15)

ax.set_xticks(angles[:-1])
ax.set_xticklabels(categories)
ax.set_title('Профиль средних баллов по предметам')
ax.legend()
plt.show()

Что показывает: профиль группы completed — «раздутый» по всем трём осям; особенно заметен разрыв по writing.

Шаг 8 — Выводы

Выводы и обоснование продукта

  1. Гипотеза подтверждена: прохождение подготовительного курса статистически значимо связано с более высокими баллами по всем трём предметам; средний прирост — порядка 5–10 баллов (≈7–12%).
  2. Эффект неоднороден: величина прироста зависит от пола, типа питания и образования родителей. Это означает, что персонализированная подготовка ценнее универсальной.
  3. Есть целевая «рисковая» группа: студенты без подготовки с низким СЭС (free/reduced lunch) — их значительная доля, и именно у них наибольший потенциал роста при подключении к программе.
  4. Продуктовая рекомендация: сервис «ExamPrep Coach» с адаптивным планом, диагностикой по трём предметам и прогнозом прироста баллов. Ключевые сегменты для запуска: (а) ученики из семей с низким СЭС, (б) ученики, чьи родители не имеют высшего образования, (в) женщины — у них выше отдача от подготовки по чтению/письму.
  5. Метрики успеха продукта: средний прирост avg_score относительно контрольной группы, доля дошедших до конца программы, NPS по сегментам.
Итог: данные показывают, что подготовка работает, но «средний» курс теряет эффективность из-за неоднородности аудитории — а значит, рынок ждёт адаптивное решение с измеримым эффектом.
